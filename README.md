# MagicLock

A high-fidelity iPhone Lock Screen simulation for performance magic.

## Features
- Indistinguishable Lock Screen, Passcode, and Home Screen visuals.
- Hidden triggers for auto-unlock and configuration.
- Time, Battery, and Notification manipulation.

## Installation
1. Install [XcodeGen](https://github.com/yonaskolb/XcodeGen).
2. Run `xcodegen generate` in the project root.
3. Open `MagicLock.xcodeproj` and build to your device.
